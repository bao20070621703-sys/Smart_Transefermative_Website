# 🇻🇳 Tiếng Việt

## 👋 Lời chào

> Chào mừng bạn đã đến với trang web của tôi. Tôi là **Vũ Huỳnh Gia Bảo**, và tôi rất vui mừng khi bạn sử dụng sản phẩm của tôi.

**Swiftly Convert App** là công cụ miễn phí, chạy hoàn toàn trên trình duyệt, giúp bạn chuyển đổi qua lại giữa **ảnh** và **tài liệu** mà vẫn giữ nguyên giao diện gốc ở mức cao nhất mà một trình duyệt cho phép.

> 🔒 **Riêng tư:** mọi dữ liệu được xử lý ngay trên máy của bạn. Không có tệp nào bị tải lên máy chủ.

## ✨ Tính năng chính

| Mục | Chi tiết |
|---|---|
| **Đầu vào** | Ảnh (JPG, PNG, WebP, BMP, GIF) và tài liệu (TXT, MD, CSV, DOCX, PDF, PPTX, XLSX, XLS). Chọn nhiều tệp cùng lúc |
| **Đầu ra** | Word `.docx`, PDF `.pdf`, PowerPoint `.pptx`, Excel `.xlsx`, văn bản `.txt`, ảnh **JPG**, ảnh **PNG**, hoặc **Tất cả** (Word + PDF + PowerPoint + Excel + TXT) |
| **Giữ định dạng** | Dựng lại từng trang với phông chữ, màu, kiểu chữ, danh sách, bảng và hình ảnh |
| **Chuyển sang ảnh** | Bảng tùy chỉnh riêng: DPI 72–600, chiều rộng px, chất lượng JPG, thang xám, thông tin ảnh xuất |
| **Cùng định dạng** | Hộp cảnh báo xác nhận, sao chép nguyên bản và tùy chọn nén |
| **Giao diện** | 4 theme (Default / Dark / Hot / Cool) và 2 ngôn ngữ (Tiếng Việt / English) |
| **Tính năng cốt lõi** | Xếp A–Z, xoay/xóa/đổi thứ tự ảnh, khổ giấy, hướng trang, lề (0 = tràn trang), cải thiện HD, giảm dung lượng |

### 🎚️ Chế độ giữ định dạng

| Chế độ | Kết quả |
|---|---|
| **Giữ nguyên giao diện gốc** *(khuyên dùng)* | Giống bản gốc về mặt hiển thị. Tệp Word/PDF/PowerPoint xuất ra chứa các trang dạng ảnh |
| **Chỉnh sửa được** | Chỉ trích chữ, tiêu đề và bảng để bạn tiếp tục sửa |

### 🖼️ Chuyển sang ảnh (JPG / PNG)

Khi chọn định dạng ảnh, một bảng tùy chỉnh hiện ra gồm:

- Định dạng ảnh, độ phân giải **72 – 600 DPI**, chiều rộng tùy chỉnh (px)
- Chất lượng JPG, chế độ màu hoặc thang xám
- Bảng **Thông tin ảnh xuất**: kích thước px, megapixel, dung lượng ước tính
- Nút **Chuyển đổi ngay** và nút **Hủy**

Ảnh xuất ra được ghi sẵn thông tin DPI. Nhiều ảnh sẽ được gói thành file ZIP.

### ⚠️ Chuyển sang đúng định dạng gốc

Trang sẽ hiện hộp **Cảnh báo** để xác nhận:

- **Có** → sao chép nguyên bản tệp (giữ nguyên phông chữ, hình ảnh, bố cục). Nếu đã tick *Giảm dung lượng file*, hình ảnh bên trong được nén lại còn phông chữ và bố cục vẫn nguyên vẹn.
- **Không** → các tệp đó bị xóa khỏi danh sách và không có chuyển đổi nào xảy ra.

## 🚀 Hướng dẫn sử dụng

1. **Thêm tệp:** kéo thả ảnh vào ô trên cùng, tài liệu vào ô *Tài liệu* (hoặc bấm vào ô để chọn tệp).
2. **Sắp xếp:** dùng `▲ ▼ ◀ ▶` để đổi thứ tự, `⟳` để xoay, `✕` để xóa.
3. **Chọn cài đặt:** khổ giấy, hướng trang, lề, chất lượng ảnh, chế độ giữ định dạng, định dạng xuất.
4. **Nếu chọn JPG hoặc PNG:** chỉnh trong bảng tùy chỉnh rồi bấm **Chuyển đổi ngay** (hoặc **Hủy** để thoát).
5. **Bấm Chuyển đổi**, rồi bấm các nút **Tải …** xuất hiện bên dưới.

## 🎨 Giao diện và ngôn ngữ

Nút **Đổi giao diện (Switch themes)** và hộp chọn ngôn ngữ nằm ở góc trên bên phải. Giao diện luôn trở về mặc định mỗi khi tải lại trang.

## ⚠️ Giới hạn cần biết

- Trình duyệt không có bộ máy dàn trang đầy đủ như Microsoft Office hay LibreOffice, nên phần dựng lại trang là bộ dựng tự xây dựng. Hỗ trợ tốt: phông chữ cài trên máy, kiểu chữ, màu, danh sách, bảng, hình ảnh (Word); chữ, hình, bảng, hình khối cơ bản (PowerPoint).
- **Chưa hỗ trợ:** đầu trang/chân trang, hộp văn bản nổi, biểu đồ, SmartArt, hiệu ứng, màu nền ô Excel.
- Ở chế độ *Giữ nguyên giao diện*, tệp xuất ra là các trang dạng ảnh nên không sửa chữ trực tiếp được. Muốn sửa, dùng chế độ *Chỉnh sửa được*. Chuyển đổi vừa giống hệt bản gốc vừa sửa được hoàn toàn cần máy chủ có bộ máy Office, điều mà một trang web tĩnh không làm được.
- PDF dạng ảnh scan không có lớp chữ nên chỉ dùng được ở chế độ giữ giao diện.
- Excel và TXT luôn chỉ xuất chữ và bảng.
- Cần có mạng trong lần chuyển đổi đầu tiên để tải các thư viện hỗ trợ.

# 🇬🇧 English

## 👋 Welcome

> Welcome to my website. I am **Vũ Huỳnh Gia Bảo**, and I am delighted that you have chosen to use my product.

**Swiftly Convert App** is a free, browser-based utility that converts **images** and **documents** into one another while preserving their original appearance as faithfully as a web browser permits.

> 🔒 **Privacy:** all processing takes place locally on your device. None of your files is ever uploaded to a server.

## ✨ Key features

| Item | Details |
|---|---|
| **Input** | Images (JPG, PNG, WebP, BMP, GIF) and documents (TXT, MD, CSV, DOCX, PDF, PPTX, XLSX, XLS), several files at once |
| **Output** | Word `.docx`, PDF `.pdf`, PowerPoint `.pptx`, Excel `.xlsx`, plain text `.txt`, **JPG** or **PNG** images, or **All** (Word + PDF + PowerPoint + Excel + TXT) |
| **Layout fidelity** | Each page is re-rendered with its fonts, colours, text styles, lists, tables and images |
| **Convert to image** | Dedicated panel: 72–600 DPI, width in px, JPG quality, greyscale, output summary |
| **Same-format files** | Confirmation dialog, intact copy and optional compression |
| **Appearance** | 4 themes (Default / Dark / Hot / Cool) and 2 languages (Vietnamese / English) |
| **Core features** | A–Z sorting, rotate/remove/reorder images, paper size, orientation, margins (0 = full-bleed), HD enhancement, file-size reduction |

### 🎚️ Layout mode

| Mode | Result |
|---|---|
| **Preserve original layout** *(recommended)* | Looks like the original. Exported Word/PDF/PowerPoint files contain page images |
| **Editable** | Only text, headings and tables are extracted so you can keep editing |

### 🖼️ Convert to image (JPG / PNG)

Choosing an image format opens a panel with:

- Image format, resolution from **72 to 600 DPI**, custom width (px)
- JPG quality, colour or greyscale mode
- An **Output image information** summary: pixel size, megapixels, estimated size
- **Convert now** and **Cancel** buttons

DPI metadata is written into every image, and multiple images are packed into a ZIP file.

### ⚠️ Converting to the original format

A **Warning** dialog asks you to confirm:

- **Yes** → the original file is copied intact (fonts, images and layout kept). If *Reduce file size* is ticked, embedded images are recompressed while fonts and layout remain untouched.
- **No** → those files are removed from the list and nothing is converted.

## 🚀 How to use

1. **Add files:** drop images in the top zone and documents in the *Documents* zone (or click a zone to browse).
2. **Organise:** use `▲ ▼ ◀ ▶` to reorder, `⟳` to rotate and `✕` to remove.
3. **Configure:** paper size, orientation, margins, image quality, layout mode and export format.
4. **If you choose JPG or PNG:** adjust the panel, then press **Convert now** (or **Cancel** to leave).
5. **Press Convert**, then use the **Download …** buttons that appear.

## 🎨 Appearance and language

**Switch themes** and the language selector are in the upper-right corner. The theme always resets to the default on reload.

## ⚠️ Known limitations

- A browser lacks a full page-layout engine such as Microsoft Office or LibreOffice, so the page renderer is custom-built. It handles installed fonts, text styles, colours, lists, tables and images (Word) and text, images, tables and basic shapes (PowerPoint).
- **Not yet supported:** headers/footers, floating text boxes, charts, SmartArt, animations, Excel cell backgrounds.
- In *Preserve original layout* mode, exported files contain page images, so the text cannot be edited directly. Use *Editable* mode when you need to edit. A conversion that is both pixel-identical and fully editable requires a server running an Office engine, which a static website cannot do.
- Scanned (image-only) PDFs have no text layer and work only in layout mode.
- Excel and TXT exports always contain text and tables only.
- An internet connection is needed on first use to load the helper libraries.

## 🌐 Publishing on GitHub Pages

1. Create a **Public** repository and upload `index.html` (**Add file → Upload files**).
2. Go to **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**.
3. After 1–2 minutes the site is live at `https://<account>.github.io/<repository-name>/`.
4. **Renaming the address:** the address is derived from the *repository name*. Go to **Settings → General → Repository name**, type the new name and click **Rename**. Suggested: `Smart_Transformative_Website` or `Swiftly-Convert-App`. The old address then stops working.
5. **Updating:** open `index.html` → **Edit** (or upload a new copy) → **Commit changes** → press `Ctrl + F5` when reloading.
