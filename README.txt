1. LỜI CHÀO
------------------------------------------------------------------------------
Chào mừng bạn đã đến với trang web của tôi. Tôi là Vũ Huỳnh Gia Bảo, và tôi rất
vui mừng khi bạn sử dụng sản phẩm của tôi.

Swiftly Convert App là công cụ miễn phí, chạy hoàn toàn trên trình duyệt, giúp
bạn chuyển đổi qua lại giữa ảnh và tài liệu mà vẫn giữ nguyên giao diện gốc ở
mức cao nhất mà một trình duyệt cho phép. Mọi dữ liệu được xử lý ngay trên máy
của bạn; không có tệp nào bị tải lên máy chủ.

------------------------------------------------------------------------------
2. TÍNH NĂNG CHÍNH
------------------------------------------------------------------------------
* Đầu vào  : ảnh (JPG, PNG, WebP, BMP, GIF) và tài liệu (TXT, MD, CSV, DOCX,
             PDF, PPTX, XLSX, XLS). Chọn được nhiều tệp cùng lúc.
* Đầu ra   : Word (.docx), PDF (.pdf), PowerPoint (.pptx), Excel (.xlsx),
             văn bản (.txt), ảnh JPG, ảnh PNG, hoặc "Tất cả" (Word + PDF +
             PowerPoint + Excel + TXT).
* Chế độ giữ định dạng:
    - "Giữ nguyên giao diện gốc" (khuyên dùng): tài liệu được dựng lại từng
      trang với phông chữ, màu sắc, kiểu chữ, danh sách, bảng và hình ảnh rồi
      mới xuất. Kết quả giống bản gốc về mặt hiển thị.
    - "Chỉnh sửa được": chỉ trích chữ, tiêu đề và bảng để bạn tiếp tục sửa.
* Chuyển sang ảnh (JPG/PNG): khi chọn định dạng ảnh, một bảng tùy chỉnh hiện ra
  gồm định dạng, độ phân giải DPI (72-600), chiều rộng tùy chỉnh (px), chất
  lượng JPG, chế độ màu/thang xám và bảng "Thông tin ảnh xuất" (kích thước px,
  megapixel, dung lượng ước tính). Có nút "Chuyển đổi ngay" và nút "Hủy".
  Ảnh xuất ra được ghi sẵn thông tin DPI. Nhiều ảnh sẽ được gói thành file ZIP.
* Cùng định dạng: nếu bạn chuyển một tệp sang chính định dạng của nó, trang sẽ
  hiện cảnh báo xác nhận.
    - "Có"   : sao chép nguyên bản tệp (giữ nguyên phông chữ, hình ảnh, bố cục).
               Nếu tick "Giảm dung lượng file", hình ảnh bên trong được nén lại
               còn phông chữ và bố cục vẫn nguyên vẹn.
    - "Không": các tệp đó bị xóa khỏi danh sách và không có chuyển đổi nào xảy ra.
* Giao diện: nút "Đổi giao diện" (Default / Dark / Hot / Cool) và nút chọn ngôn
  ngữ (Tiếng Việt / English) ở góc trên bên phải. Giao diện luôn trở về mặc định
  mỗi khi bạn tải lại trang.
* Giữ nguyên các tính năng cốt lõi: xếp A-Z, xoay/xóa/sắp xếp ảnh, khổ giấy,
  hướng trang, lề (0 = tràn trang), cải thiện HD, giảm dung lượng file.

------------------------------------------------------------------------------
3. HƯỚNG DẪN SỬ DỤNG
------------------------------------------------------------------------------
Bước 1. Thêm tệp: kéo thả ảnh vào ô trên cùng, tài liệu vào ô "Tài liệu" (hoặc
        bấm vào ô để chọn tệp).
Bước 2. Sắp xếp: dùng các nút ▲ ▼ ◀ ▶ để đổi thứ tự, ⟳ để xoay, ✕ để xóa.
Bước 3. Chọn cài đặt: khổ giấy, hướng trang, lề, chất lượng ảnh, chế độ giữ
        định dạng và định dạng xuất.
Bước 4. Nếu chọn JPG hoặc PNG: chỉnh trong bảng tùy chỉnh rồi bấm "Chuyển đổi
        ngay" (hoặc "Hủy" để thoát).
Bước 5. Bấm "Chuyển đổi", rồi bấm các nút "Tải ..." xuất hiện bên dưới.

4. GIỚI HẠN CẦN BIẾT (xin trình bày trung thực)
------------------------------------------------------------------------------
* Trình duyệt không có bộ máy dàn trang đầy đủ như Microsoft Office hay
  LibreOffice, nên phần "dựng lại trang" là bộ dựng tự xây dựng. Nó hỗ trợ tốt:
  phông chữ cài trên máy, kiểu chữ, màu, danh sách, bảng, hình ảnh (Word);
  chữ, hình, bảng, hình khối cơ bản (PowerPoint). Chưa hỗ trợ: đầu trang/chân
  trang, hộp văn bản nổi, biểu đồ, SmartArt, hiệu ứng, màu nền ô Excel.
* Ở chế độ "Giữ nguyên giao diện", tệp Word/PDF/PowerPoint xuất ra chứa các
  trang dạng ảnh nên không sửa chữ trực tiếp được. Muốn sửa chữ, dùng chế độ
  "Chỉnh sửa được". Chuyển đổi vừa giống hệt bản gốc vừa sửa được hoàn toàn
  cần máy chủ có bộ máy Office, điều mà một trang web tĩnh không làm được.
* PDF dạng ảnh scan không có lớp chữ nên chỉ dùng được ở chế độ giữ giao diện.
* Excel và TXT luôn chỉ xuất chữ và bảng.
* Cần có mạng trong lần chuyển đổi đầu tiên để tải các thư viện (jsPDF, SheetJS,
  pdf.js, pdf-lib, PptxGenJS). Các nút AI không có trong phiên bản này.

1. WELCOME
------------------------------------------------------------------------------
Welcome to my website. I am Vũ Huỳnh Gia Bảo, and I am delighted that you have
chosen to use my product.

Swiftly Convert App is a free, browser-based utility that converts images and
documents into one another while preserving their original appearance as
faithfully as a web browser permits. All processing takes place locally on your
device; none of your files is ever uploaded to a server.

------------------------------------------------------------------------------
2. KEY FEATURES
------------------------------------------------------------------------------
* Input   : images (JPG, PNG, WebP, BMP, GIF) and documents (TXT, MD, CSV, DOCX,
            PDF, PPTX, XLSX, XLS), several files at once.
* Output  : Word (.docx), PDF (.pdf), PowerPoint (.pptx), Excel (.xlsx), plain
            text (.txt), JPG or PNG images, or "All" (Word + PDF + PowerPoint +
            Excel + TXT).
* Layout mode:
    - "Preserve original layout" (recommended): each page is re-rendered with
      its fonts, colours, text styles, lists, tables and images before export,
      so the result looks like the original.
    - "Editable": only text, headings and tables are extracted for editing.
* Convert to image (JPG/PNG): choosing an image format opens an advanced panel
  with image format, resolution (72-600 DPI), custom width (px), JPG quality,
  colour/greyscale mode and an "Output image information" summary (pixel size,
  megapixels, estimated size), with "Convert now" and "Cancel" buttons. DPI
  metadata is written into every image; multiple images are packed into a ZIP.
* Same-format conversion: converting a file to its own format triggers a
  confirmation dialog.
    - "Yes": the original file is copied intact (fonts, images and layout kept).
             If "Reduce file size" is ticked, embedded images are recompressed
             while fonts and layout remain untouched.
    - "No" : those files are removed from the list and nothing is converted.
* Appearance: "Switch themes" (Default / Dark / Hot / Cool) and a language
  selector (Vietnamese / English) in the upper-right corner. The theme always
  resets to the default on reload.
* Core features retained: A-Z sorting, rotate/remove/reorder images, paper size,
  orientation, margins (0 = full-bleed), HD enhancement, file-size reduction.

------------------------------------------------------------------------------
3. HOW TO USE
------------------------------------------------------------------------------
Step 1. Add files: drop images in the top zone and documents in the "Documents"
        zone (or click a zone to browse).
Step 2. Organise: use the arrow buttons to reorder, the rotate button to rotate
        and the cross to remove.
Step 3. Configure: paper size, orientation, margins, image quality, layout mode
        and export format.
Step 4. If you choose JPG or PNG: adjust the panel, then press "Convert now"
        (or "Cancel" to leave without converting).
Step 5. Press "Convert", then use the download buttons that appear.

------------------------------------------------------------------------------
4. KNOWN LIMITATIONS (stated candidly)
------------------------------------------------------------------------------
* A browser lacks a full page-layout engine such as Microsoft Office or
  LibreOffice, so the page renderer is a custom-built one. It handles installed
  fonts, text styles, colours, lists, tables and images (Word) and text, images,
  tables and basic shapes (PowerPoint). It does not yet support headers/footers,
  floating text boxes, charts, SmartArt, animations or Excel cell backgrounds.
* In "Preserve original layout" mode, exported Word/PDF/PowerPoint files contain
  page images, so the text cannot be edited directly. Use "Editable" mode when
  you need to edit. A conversion that is both pixel-identical and fully editable
  requires a server running an Office engine, which a static website cannot do.
* Scanned (image-only) PDFs have no text layer and work only in layout mode.
* Excel and TXT exports always contain text and tables only.
* An internet connection is needed on first use to load the helper libraries
  (jsPDF, SheetJS, pdf.js, pdf-lib, PptxGenJS). AI buttons are not included.

5. PUBLISHING ON GITHUB PAGES
------------------------------------------------------------------------------
1) Create a Public repository and upload index.html (Add file > Upload files).
2) Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
3) After 1-2 minutes the site is live at:
       https://<account>.github.io/<repository-name>/
4) Renaming the address: the address is DERIVED FROM THE REPOSITORY NAME and is
   not stored in index.html. To correct a misspelt name (for example
   "Smart_Transefermative_Website"), open the repository > Settings > General >
   Repository name > type the new name > Rename. Suggested names:
   "Smart_Transformative_Website" or "Swiftly-Convert-App". The old address then
   stops working; the new one is https://<account>.github.io/<new-name>/ .
5) To update: open index.html in the repository > Edit (or upload a new copy to
   overwrite it) > Commit changes > press Ctrl + F5 when reloading the page.
